# 轉爐石台北港專案 (617000928) 數據與船次進度儀表板

本專案提供中聯資過磅資料（台北港轉爐石）的彙總數據分析與船次作業進度查詢儀表板。支援 **API 即時連線同步** 與 **本機自動化發布** 雙軌架構。

👉 **[https://didr93521242-lab.github.io/tpg-project-617000928/](https://didr93521242-lab.github.io/tpg-project-617000928/)**

## 🚀 資料同步與產出方式

### 方式一：儀表板前端即時連線（內網環境）
- 在內網環境開啟儀表板首頁（`index.html`）。
- 點擊頂部 **「🌐 API 即時同步」** 按鈕，瀏覽器將直接向 API 端點請求最新 15 萬+ 筆資料，即時運算並刷新全部船次與圖表。
- 支援透過旁邊的 **「設定」** 按鈕調整 API 連線端點或 Token。

### 方式二：一鍵自動化發布至 GitHub Pages（管理員）
1. 雙擊執行本機 `publish_api.bat`（或 `publish_and_push.bat`）。
2. 系統自動自 API 端點擷取最新過磅出廠數據（若 API 離線則自動退回讀取本機 Google Drive Excel 備援）。
3. 自動完成跨年度統計、船次自動分群（GAP > 4 天）、資料匿名化彙總，並產出 `docs/data/project-data.json`。
4. 自動透過 Git 提交並推播至 GitHub Pages。

## 🔒 資訊安全與權限設計
1. **外部訪客（純唯讀查詢）**：
   - 僅可查看 KPI 統計、年度趨勢、船次進度、作業速率與小時分布圖表。
   - 所有公開資料均經由嚴格**匿名化彙總**，不包含任何原始車號、磅單號或司機明細。
2. **管理員（資料同步與管理）**：
   - 具備直連 API 取得完整過磅明細、車輛週轉率與單號紀錄之權限。
